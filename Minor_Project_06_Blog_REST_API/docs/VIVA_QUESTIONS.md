# Viva Questions and Answers

1. **What is Node.js?** A JavaScript runtime that executes JavaScript outside a browser.
2. **What is Express.js?** A Node.js web framework for routing and middleware.
3. **What is a REST API?** An interface that exposes resources through URLs and standard HTTP methods.
4. **What is CRUD?** Create, Read, Update and Delete.
5. **Which methods are used?** POST creates, GET reads, PUT updates and DELETE removes.
6. **What is middleware?** A function in the request-response cycle, used for parsing, CORS and error handling.
7. **What is routing?** Mapping an HTTP method and URL to a handler.
8. **What is a controller?** Code that handles a request, performs logic and sends a response.
9. **Why validate input?** To prevent missing or invalid data from being saved.
10. **Why status 201?** It indicates that a resource was successfully created.
11. **What does 404 mean?** The requested resource or route was not found.
12. **Where is data stored?** In `data/posts.json`.
13. **Why separate routes and controllers?** To keep URL definitions separate from application logic.
14. **What does express.json() do?** Parses JSON request bodies into `req.body`.
15. **Why use Postman?** To send API requests and inspect responses without a frontend.
16. **What is pagination?** Dividing results into pages; this API supports page and limit.
17. **Is MongoDB used?** No, JSON file storage is used, which is one of the assignment's allowed options.
18. **What does next(error) do?** Passes an error to centralized Express error middleware.
19. **What if an ID does not exist?** The API returns 404 with a JSON message.
20. **Possible future features?** MongoDB, JWT authentication, Swagger and deployment.
